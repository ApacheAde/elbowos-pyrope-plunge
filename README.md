# Pyrope Plunge

Full-colour **Python 3** neon gem-diver arcade for [ElbowOS](https://x.com/ElbowOS).

Steer a burning pyrope crystal down a vertical shaft.
Thread gold scoring rings. Spinning ember blades nick a life.
A / D or ← → to drift. R resets.

## Play

```
pip install -r requirements.txt
python3 pyrope_plunge.py --play
```

## Record a 9:16 reel

```
python3 pyrope_plunge.py --record
```

Writes `/home/workdir/artifacts/PYROPE_PLUNGE_ElbowOS.mp4` (1080×1920, 15s, 30fps, H.264).
